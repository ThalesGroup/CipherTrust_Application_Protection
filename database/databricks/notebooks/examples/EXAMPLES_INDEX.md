# Examples Index

This directory contains runnable example notebooks that are not smoke tests,
setup notebooks, or benchmarks.

## Policy-Specific Example Folders

### `internal/`

- `compute_cluster_java_udf_sql_examples.py`
  SQL-shaped Java UDF examples for compute-cluster use.
- `internal_helper_dataframe_adls_load.py`
- `internal_java_udf_sql_adls_load.py`
- `internal_pandas_udf_examples.py`

### `external/`

- `compute_cluster_java_udf_sql_examples_external_round_trip.py`
  Expanded Java SQL example with a fuller external-policy round trip.
- `external_pandas_udf_examples.py`

### `no_version/`

- `none_pandas_udf_examples.py`

## Relationship To Other Notebook Areas

- `notebooks/benchmarks/`
  performance notebooks only
- `notebooks/smoke_tests/`
  validation and readiness notebooks
- `notebooks/setup/`
  one-time sample object creation notebooks
- `notebooks/utils/`
  shared helper notebooks and supporting utilities
